# Cinema Look Lab

시네마틱 색감을 비교하고 직접 조절하는 사진 학습용 웹앱입니다. 빌드·API 키·유료 서비스가 필요하지 않습니다.

- 21개 창작 근사 룩, 각 룩마다 샘플 3장(총 63장)
- 노출·화이트밸런스·RGB 커브·8색 HSL·컬러 그레이딩·디테일·빛 번짐
- 룩을 선택하면 편집 가능한 경향값을 자동 입력
- 원본 비교, 룩 강도, 개인 사진 불러오기, JPG 저장
- iPad 가로/세로 반응형 패널과 고정 이미지 영역
- 마지막 샘플·조절값·커브·강도를 기기의 브라우저에 저장

## 실행

```sh
cd dist
python3 -m http.server 8080
```

`http://localhost:8080`에서 엽니다. Web Worker를 사용하므로 로컬에서도 HTTP 서버 실행을 권장합니다. Worker가 지원되지 않으면 기본 처리 방식으로 실행됩니다.

## GitHub Pages

`.github/workflows/pages.yml`은 main 브랜치에 push하면 테스트 후 `dist`를 배포합니다. Pages가 활성화되지 않았다면 저장소 Settings → Pages → Source를 **GitHub Actions**로 설정한 뒤 Actions에서 워크플로를 다시 실행하세요.

## 최적화

- 색 변환은 별도 Web Worker에서 처리해 UI 작업과 분리합니다.
- 픽셀마다 만들던 임시 배열과 반복 계산을 줄였습니다.
- 슬라이더를 조절하는 동안 720px, 멈추면 최대 1280px로 처리합니다.
- 비교선·원본 보기·룩 강도 변경은 보정 결과를 재사용합니다.
- 룩 카드는 미리 계산한 작은 WebP를 지연 로딩합니다.
- 샘플은 WebP이며 현재 선택한 사진만 불러옵니다.
- 연속 입력은 최신 요청만 반영하며 이전 사진의 늦은 결과는 버립니다.

컨테이너의 1280×853 색 변환 비교에서 기존 7,656ms → 최적화 368ms였고 테스트 색 결과는 동일했습니다. 전체 앱 속도나 실제 기기의 성능 보장은 아닙니다. 블러는 브라우저 필터 의존성을 없애고 기기 간 일관된 소프트 블러 연산으로 처리합니다.

## 검증

```sh
node --test tests/*.test.cjs
```

21개 룩의 216색 회귀 결과, 효과의 출력, 샘플·썸네일 누락, 룩 기준값·중립화·샘플 전환·개인 사진 유지·설정 복원·비교 캐시를 검사합니다.

## 사진과 표현

샘플은 내장 image_gen 도구로 생성한 중립적인 BEFORE 이미지이며 RAW 원본이 아닙니다. 장면별 생성 프롬프트와 파일 목록은 `dist/samples/manifest.json`에 있습니다. `dist/thumbs`는 앱 엔진으로 미리 렌더링한 카드 미리보기입니다.

브랜드·작가 이름이 붙은 룩은 공식 LUT·필름 시뮬레이션이 아닌 창작 근사 표현입니다. 조절값은 학습용 경향값이며 Lightroom에 그대로 복사하는 공식 프리셋 수치가 아닙니다. 불러온 개인 사진은 서버로 전송하지 않습니다. 브라우저에 개인 사진 파일 자체를 저장하지는 않습니다.
